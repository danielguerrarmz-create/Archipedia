# Persona walkthrough — findings (2026-06-14)

Each of the four personas reviewed every page of the live frontend (backend off),
by eye first, then with code. Consolidated and de-duplicated below. Severity is the
max across personas; "voices" notes who raised it.

## Fixed in this pass
- **[P0] Raw HTTP 500 on direct load / refresh / shared link of `/search/classic`
  and `/boards`.** *(All 4 voices.)* Root cause (Dev diagnosed): the Vite dev proxy
  forwarded `/search`, `/boards`, `/images`, `/generate` as path *prefixes*, so SPA
  routes collided with the API namespace and were proxied to the offline backend.
  **Fix:** `vite.config.ts` proxy now has a `bypass` that serves the SPA for browser
  navigations (Accept: text/html) while still proxying real API/asset calls.
  Verified: `/search/classic` and `/boards` now return 200 (SPA) on direct load.
- **[P0] No fabricated precedent on failure.** *(Dev/Lena/Marcus watched for this.)*
  Confirmed passing — the canvas mock-results fallback was removed; Classic, Canvas
  (red "error" node), RUN toast, and Boards all fail honestly. This is the trust floor
  and it now holds consistently.
